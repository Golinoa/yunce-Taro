门店入驻

落地页设计拆解

这是「松果排课」门店入驻落地页的 HTML 样板，用于借鉴视觉层次与文案结构。

一、结构节奏

  • Hero 强主张 → 数据背书（叠层）→ 痛点共鸣 → 功能 → 理由 → 流程 → 收尾 CTA
  • 每个模块独立成 section，间距 34px 形成呼吸感
  • 全程围绕「入驻」一个转化目标，CTA 出现 3 次

二、视觉技巧

  • 主色存于 CSS 变量，右侧圆点可一键换主题
  • 数据卡「叠」在 Hero 下缘（负 margin），制造层次
  • 卡片 hover 上浮 + 阴影加深，增强可点击暗示
  • 流程第一步高亮为主题渐变，形成引导视线
  • Hero 用光斑圆 + 呼吸圆环动画，克制不喧宾夺主

三、文案原则

  • 只说真实能力，不虚构「服务 XX 万场馆」等数字
  • 痛点用「第一人称抱怨」，引发共鸣而非说教
  • 差异化定位一句话：「馆主做给自己用」

四、换主题试试
