写作原则
  1. 陈述事实 → 说明影响 → 给出可选下一步；不用「对了 / 好像 / 咱们」等过口语。
  2. 幽默克制：一处轻点即可（如「不必为名额让步」），不卖萌、不玩梗。
  3. 避免套话：「不是催单」「我们一直在」「好久没见」等一律不用。
  4. 同屏一条；关闭后 7 日内同 tipId 不再展示。优先级：已到期 > ≤7 天 > ≤30 天 > 配额/能力。
