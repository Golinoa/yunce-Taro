|------|------|----------|

## 二、头部区域渐变

```css
background: linear-gradient(
  180deg,
  #4a7dff 0%,
  #5b8cff 15%,
  #8ab4ff 40%,
  #c8d8ff 65%,
  #eef2ff 85%,
  #fff 100%
);
```

| 色值 | 位置 | 说明 |
|------|------|------|
| `#4a7dff` | 0% | 最深，顶部状态栏/导航栏背景 |
| `#5b8cff` | 15% | 次深 |
| `#8ab4ff` | 40% | 中等 |
| `#c8d8ff` | 65% | 浅淡 |
| `#eef2ff` | 85% | 极淡 |
| `#fff` | 100% | 白色，与下方内容区衔接 |

**辅助白色透明层**：
- `rgba(255,255,255,0.15)` — 状态栏时间背景
- `rgba(255,255,255,0.8)` — 电池边框/电池头
- `rgba(255,255,255,0.7)` — 定位图标背景
- `rgba(255,255,255,0.85)` — 机构名称文字
- `rgba(255,255,255,0.6)` — 定位文字

## 九、配色总结

### 主色调
- **主题蓝**：`#4a7dff`（品牌主色）
- **辅助蓝**：`#5b8cff`、`#8ab4ff`、`#74a3ff`

### 背景层次
1. 头部：`#4a7dff` → `#fff` 渐变
2. 底图：`#fff`（纯白）
3. 大卡片：`#eef5ff` → `#e0ecff`
4. 小卡片：`#f5f8ff`

### 功能色（图标）
- 青绿：`#00b894`
- 紫罗兰：`#6c5ce7`
- 橙黄：`#ff9f43`
- 玫红：`#e84393`
- 天蓝：`#0984e3`
-  slate灰：`#636e72`
- 青色：`#00c9c9`

### 强调色
- 红色：`#FF4D4F`、`#ff4757`、`#ff6b6b`
- 粉红：`#ff7b8a`
- 金黄：`#FFD600`
