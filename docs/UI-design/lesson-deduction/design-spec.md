## 三、核心交互设计

### 3.1 课包自动匹配（无感选择）

单人消课模式下，选择学员后系统自动匹配最优课包，用户无需手动选择：

**匹配优先级：**
1. 有科目标签且余额充足的课包
2. 通用课包（无科目标签）且余额充足
3. 任意有余额的课包
4. 第一个课包（即使余额为0）

匹配结果直接显示在学员卡片右侧（剩余课时 + 课包名称），无需额外操作步骤。

### 3.2 班级选择与更换

**初始状态：** 显示所有班级列表，每项带圆形勾选框
**选中后：** 其他班级隐藏，只显示选中班级 + 绿色"更换"按钮
**点击更换：** 弹出底部弹窗，列出所有班级（当前班级置灰），点击其他班级即切换

### 3.3 学员签到勾选

班级消课中学员名单使用圆形勾选框：
- **默认全部勾选**（签到）
- **取消勾选** = 没来上课（整行变半透明）
- **点击整行**即可切换签到状态
- 顶部显示签到人数统计 `(签到 3/5)`

### 3.4 欠课与无课包提示

| 状态 | 样式 | 说明 |
|------|------|------|
| 余额充足 | 绿色标签 `钢琴 · 剩余18课时` | 正常状态 |
| 余额不足 | 黄色标签 `欠课 · 钢琴仅剩2课时` | 黄色背景+边框 |
| 无课包 | 红色标签 `无可用课包` | 红色背景+边框 |

### 3.5 学员选择弹窗

底部弹出，包含：
- 搜索框（支持姓名/手机号搜索）
- 学员列表（头像 + 姓名 + 手机号）
- 点击即选中并关闭弹窗

### 3.6 班级更换弹窗

底部弹出，包含：
- 所有班级列表（图标 + 名称 + 时间 + 人数）
- 当前班级置灰不可选
- 点击其他班级即切换并关闭弹窗

```typescript
interface Subject {
  id: string;
  name: string;       // 科目名称
  icon: string;       // emoji图标

interface Student {
  id: string;

  nickname?: string;  // 昵称

```

### 5.3 课包

```typescript
interface Package {
  id: string;
  name: string;           // 课包名称
  subjectId: string|null; // 关联科目ID，null为通用课包
  total: number;          // 总课时
  remaining: number;      // 剩余课时

  role: 'owner'|'sharer';// 角色：拥有/共享

}
```

### 5.4 班级

interface Class {

## 六、业务规则

### 6.1 单人消课

1. 选择学员后自动匹配课包，无需手动选择
2. 课包匹配优先级：科目匹配 > 通用课包 > 任意有余额 > 第一个
3. 余额为0时仍可消课（欠课状态），显示红色警告
4. 消课课时最小0.5，步进0.5
5. 提交按钮显示扣减课时数

### 6.2 班级消课

1. 选择班级后自动加载学员名单
2. 学员默认全部签到（勾选），取消勾选=没来
3. 每个学员自动匹配该班级科目的课包
4. 选中班级后其他班级隐藏，通过"更换"按钮切换
5. 提交按钮显示签到人数和每人课时

### 6.3 欠课处理

- 余额不足时仍允许消课，标记为欠课
- 欠课学员显示黄色背景和提示文字
- 无课包学员显示红色背景和警告文字
