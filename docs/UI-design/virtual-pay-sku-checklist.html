3. 权限

小程序

  • 查看会员页 / 下单：仅 principal（校长）或 admin（管理员）
  • 其它角色：提示「仅校长/管理员可查看会员权益」
  • API：POST /payments/membership/orders 校验校长机构，否则 403

运营后台

  • 配置机构版本 / virtualProductId：运营人员（后台登录权限）
  • 给机构改档、发激活码、补差升级：运营人工
  • 众创申请 / 试用发放 / 校区加购：不走虚拟支付

不开放自助的

  • 版本升级补差（任意金额）
  • 额外校区 +¥200
  • 众创 / 试用 / 公益免费

4. 服务端环境

  • VIRTUAL_PAY_OFFER_ID
  • VIRTUAL_PAY_APP_KEY
  • 可选本地：VIRTUAL_PAY_MOCK=true（生产禁止）
  • 支付结果推送：微信消息推送 URL / Token / EncodingAESKey（按现网支付文档）

可购判定（代码）

  • GET /payments/membership/skus 只返回有道具 ID 且 price>0 的 active 版本
  • 小程序：有匹配 durationDays（≈730/1095）的 SKU 才显示「实付」

5. 验收清单

  • 微信 6 正式 + 2 测试道具已创建（含 yunce_test_pay_1y 与 sku_test_1fen），价格与表一致
  • 后台 8 行版本已填 virtualProductId / price / durationDays（含 TEST_PAY + TEST_PAY_1FEN）
  • 生产未开启 VIRTUAL_PAY_MOCK
  • 校长账号：选「成长-3年」可下单并履约（或 MOCK 通）
  • 两条测试道具均保留；仅测试机构/测试账号可测；测完可各自下架或清空道具 ID
  • 员工/教练账号：无法进入会员购买
  • 升级 / 加校区：走企微，无任意金额支付入口
