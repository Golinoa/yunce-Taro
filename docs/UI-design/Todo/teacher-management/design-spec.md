# 教师管理模块 UI 设计说明

> 原型文件：`scheme-a-list-detail.html`（浏览器打开即可预览）

---

## 一、业务定位

**教师管理**是教务端核心模块，管理机构的教师信息、薪资发放和排课安排。核心特征：
- **教务管理员操作**，非教师自助
- 薪资仅记录和确认，不接入真实支付
- 支持多种工资模型（标准主讲/纯课时/自定义）
- 支持批量确认和发放，发放需二次确认+备注

---

## 二、页面结构

```
主页面（三Tab：教师/薪资/排课）
├── 教师Tab：教师列表 + 筛选
├── 薪资Tab：本月/历史/设置 三子Tab
│   ├── 本月：发薪提醒 + 快捷入口 + 薪资明细 + 批量操作
│   ├── 历史：年月选择器 + 历史记录列表
│   └── 设置：发薪日/推送/自动确认/工资模型
└── 排课Tab：周视图 + 日课表

教师详情页（四Tab：薪资/课时/反馈/排课）
└── 薪资Tab：当月工资 + 工资模型 + 工资记录

工资单详情页（独立页面）
└── 状态流转 + 金额构成 + 课时明细 + 扣款/补发
```

## 三、业务流程

### 3.1 薪资流转

```
待确认 → 已确认 → 已发放
```

- **待确认 → 已确认**：单个确认（薪资卡片按钮）/ 批量确认
- **已确认 → 已发放**：需二次确认弹窗，可填写备注（单个发放 / 批量发放）
- **已发放**：终态，不可回退

### 3.2 发放确认弹窗

- 显示教师姓名和发放金额
- 备注输入（选填），支持多行文本
- 单个发放：显示"确认发放"
- 批量发放：显示"确认发放 N 人"及总额

### 3.3 年月选择器

- 点击月份标题弹出选择面板
- 年份左右箭头切换
- 4x3 月份网格，当前月高亮，未来月份禁用
- 选择后自动关闭并刷新数据
- 点击外部自动关闭

### 3.4 教师筛选

- 三维筛选：角色（全部/主讲/助教/兼职）+ 科目（全部/钢琴/声乐/...）+ 状态（在职/全部/已离职）
- 下拉菜单互斥选择

### 3.5 排课

- 周视图导航，左右切换周
- 点击日期查看当日课表
- 课表按时间线展示，显示课程名/人数/教室/教师/费率
- 点击教师标签可跳转教师详情

## 四、数据模型

### 4.1 教师数据

```typescript
interface Teacher {
  id: number
  name: string
  role: 'lead' | 'assist' | 'parttime'
  roleText: string
  subject: string
  phone: string
  hours: number
  students: number
  classes: number
  base: number        // 底薪
  rate: number        // 课时费单价
  attend: number      // 全勤奖
  perf: number        // 绩效奖金
  salaryStatus: 'pending' | 'confirmed' | 'paid'
  modelIdx: number    // 工资模型索引
  color: string       // 头像渐变色
  initial: string     // 头像首字
  deductions: Deduction[]
  payRemark?: string  // 发放备注
  status: 'active' | 'resigned'
  resignType?: string
  resignDate?: string
  resignReason?: string
}
```

### 4.2 扣款/补发

```typescript
interface Deduction {
  reason: string
  amount: number
  type: 'deduct' | 'bonus'
}
```

### 4.3 工资模型

| 模型 | 底薪 | 课时费 | 全勤奖 | 绩效 |
|------|------|--------|--------|------|
| 标准主讲 | 3000 | 统一/按班级 | 500 | 700 |
| 纯课时 | 0 | 统一/按班级 | 0 | 0 |
| 自定义 | 自定义 | 自定义 | 自定义 | 自定义 |

## 五、弹窗清单

| 弹窗 | 触发 | 功能 |
|------|------|------|
| 添加教师 | 顶部"添加教师"按钮 | 姓名+手机+科目+角色+工资模型 |
| 编辑教师 | 详情页编辑按钮 | 同上，回填数据 |
| 工资模型 | 设置页"新建薪资模板" | 模型名称+类型+参数+分配教师 |
| 发放设置 | 设置页"修改" | 发薪日+提前推送天数 |
| 扣款/补发 | 工资单详情"+"按钮 | 类型+原因+金额 |
| 更多操作 | 详情页更多按钮 | 标记离职+导出记录 |
| 发放确认 | 发放按钮 | 二次确认+备注 |
| 年月选择器 | 历史月份标题 | 年份切换+月份网格 |
