# 学员管理 — UI 设计审查报告

> 审查日期：2026-06-14
> 审查范围：原型文件 + 设计规范 + 迁移方案
> 问题统计：P0: 2 / P1: 4 / P2: 3

---

## 一、业务流程验证

### 完整流程
```
学员列表 → 搜索/筛选/排序 → 点击卡片 → 学员详情 → Tab切换(课时记录/课包/请假/家长)
                                                              ↓
                                                        充值/编辑/删除
```

### P0 严重问题

#### P0-1: 删除学员无级联提示
**问题**: 删除确认弹窗(`showDeleteModal`)只显示"确认删除该学员吗？"，未提示关联数据影响。学员可能关联课包、课时记录、家长绑定，删除后数据如何处理未说明。

**影响范围**: 数据安全
**建议**: 确认弹窗应显示关联信息："该学员有X个进行中课包、Y条课时记录、Z位绑定家长，删除后数据将如何处理？"。需后端明确删除策略（软删除/归档/级联删除）。

#### P0-2: 欠课学员无补课入口
**问题**: 欠课学员卡片显示了欠课徽章和缺课日期，但没有任何补课操作入口。欠课是核心业务痛点，仅有展示无操作是流程断层。

**影响范围**: 核心业务闭环
**建议**: 欠课提示条增加"安排补课"按钮，跳转消课页面并预填学员信息；或在详情页课时记录Tab中增加"补课"快捷操作。

## 二、缺失项识别

### P1 重要问题

#### P1-1: 学员列表缺少批量操作
**问题**: 当前只能逐个操作学员，无法批量选择、批量删除、批量发送通知。当学员数量多时效率极低。

**建议**: 列表页增加"管理"模式，支持多选+批量操作（批量发通知/批量标记/批量导出）。

#### P1-2: 详情页缺少课包充值快捷入口
**问题**: 底部操作栏有"课时充值"按钮，但课包Tab中的课包卡片没有"续费/充值"快捷入口。用户需要返回详情页底部才能充值，操作路径长。

**建议**: 课包卡片增加"续费"按钮（余额不足时高亮），直接跳转充值页并预填课包信息。

#### P1-3: 家长绑定缺少邀请方式
**问题**: 家长Tab只有邀请码展示和复制，缺少：1) 微信分享邀请链接；2) 扫码绑定；3) 手动输入手机号绑定。仅靠邀请码不够便捷。

**建议**: 增加"微信分享邀请"按钮（生成小程序分享卡片）和"扫码绑定"入口。

#### P1-4: 请假记录缺少操作入口
**问题**: 请假Tab只展示请假记录列表，缺少：1) 新增请假入口；2) 销假操作；3) 请假审批流程（如需教师确认）。

**建议**: 增加请假操作：添加请假（选择日期+原因）、销假（标记已恢复上课）。

## 三、设计一致性

### P2 一般问题

#### P2-1: 科目筛选硬编码
**问题**: 筛选栏的科目选项(piano/vocal/theory/calligraphy/general)是硬编码的，与校区设置模块的科目管理不联动。不同校区科目不同，应从后端动态获取。

**建议**: 科目筛选列表应从校区设置模块的SUBJECTS数据动态生成，保持数据源统一。

#### P2-2: 统计摘要数据来源不明
**问题**: 头部统计摘要(总学员/充足/不足/欠课)的数据来源未定义。是前端从列表数据计算，还是后端单独接口返回？

**建议**: 建议后端在学员列表接口中附带summary字段，避免前端遍历计算。学员数>200时前端计算不可行。

#### P2-3: 搜索仅前端过滤
**问题**: 当前搜索为前端实时过滤(`handleSearch`)，学生数超过200时性能不可行。

**建议**: 搜索应改为后端API调用，前端300ms防抖后发起请求。当前原型可保留前端过滤作为演示，但迁移时必须改为后端搜索。

## 四、落地可行性

| 风险项 | 等级 | 说明 |
|--------|------|------|
| 欠课数据接口 | 高 | 欠课学员的缺课节数和日期列表需后端新增接口 |
| 课包到期提醒 | 中 | "即将过期"需定义天数阈值(建议30天)，需后端配合 |
| 搜索性能 | 中 | 学员数>200需后端搜索，前端过滤不可行 |
| 头像渐变色 | 低 | 5组循环色，纯前端逻辑，无风险 |
| backdrop-filter兼容性 | 低 | 微信小程序基础库2.9+支持，需注意低版本降级 |

## 五、与其他模块的关联风险

| 关联模块 | 风险 |
|----------|------|
| 校区设置 | 科目筛选应从校区科目动态获取，删除科目需同步筛选选项 |
| 课时充值 | 详情页充值按钮需携带学生ID+课包ID跳转 |
| 消课流程 | 欠课学员的补课入口应跳转消课页并预填信息 |
| 添加学员 | 头部"添加学员"按钮跳转添加学员页面 |
| 通知设置 | 课时不足续费提醒与通知设置模块联动 |
