# 学员管理 - 设计标注文档

> 基于 `student-management.html` 原型，覆盖学员列表页 + 学员详情页

---

## 一、业务定位

| 属性 | 说明 |
|------|------|
| 使用角色 | 教师（主）/ 家长（只读） |
| 核心功能 | 学员列表浏览、搜索筛选、课时预警、学员详情查看、课包/记录/请假/家长管理 |
| 业务约束 | 家长仅可查看绑定学员，不可编辑/删除；教师拥有完整操作权限 |

## 八、组件交互规格

### 8.1 排序下拉 (SortSelect)

**位置**：头部搜索框右侧

| 属性 | 规格 |
|------|------|
| 触发器尺寸 | 36×36px |
| 触发器圆角 | 10px |
| 触发器背景 | `rgba(255,255,255,0.22)` + `backdrop-filter: blur(4px)` |
| 触发器active背景 | `rgba(255,255,255,0.4)` |
| 图标尺寸 | 18×18px，默认 `rgba(255,255,255,0.85)`，active 白色 |
| 下拉面板 | 右对齐，min-width 140px，圆角12px，白色背景，阴影 `0 8px 24px rgba(0,0,0,0.12)` |
| 选项内边距 | 10px 12px |
| 选项字号 | 13px |
| 选项选中态 | `--primary-bg` 背景 + `--primary` 文字 + 加粗 |

**排序选项**：

| 值 | 标签 | 排序规则 |
|----|------|---------|
| default | 默认排序 | 保持原有顺序（通常为创建时间倒序） |
| hours-desc | 课时从多到少 | 按剩余课时降序 |
| hours-asc | 课时从少到多 | 按剩余课时升序 |
| name-asc | 姓名A-Z | 按姓名拼音升序 |
| name-desc | 姓名Z-A | 按姓名拼音降序 |

**交互规则**：
- 点击排序按钮展开下拉面板，同时关闭其他下拉（筛选下拉）
- 选择选项后更新显示文本，关闭面板，应用排序
- 点击外部区域关闭下拉面板
- 排序与筛选可同时生效，排序作用于筛选后的结果

## 九、交互规格

### 9.1 排序交互

| 交互 | 行为 |
|------|------|
| 点击排序按钮 | 展开排序下拉面板，同时关闭其他下拉面板 |
| 选择排序选项 | 更新按钮显示文本，关闭面板，重新排列列表 |
| 点击外部 | 关闭排序下拉面板 |
| 默认排序 | 保持服务器返回的原始顺序（通常为创建时间倒序） |
| 课时排序 | 按剩余课时数字值排序，支持升序/降序 |
| 姓名排序 | 按姓名拼音排序，支持 A-Z/Z-A |
| 排序+筛选 | 排序作用于筛选后的结果集 |

### 9.2 搜索交互

| 交互 | 行为 |
|------|------|
| 输入文字 | 实时过滤学员列表（防抖 300ms） |
| 清除按钮 | 输入框有内容时显示，点击清空并恢复列表 |

| 搜索范围 | 姓名、手机号模糊匹配 |

## 十、状态流转

### 10.1 列表页状态

```
初始加载 → 加载中 → 数据就绪
                       │
          ┌────────────┼────────────┐
          │            │            │
      有学生数据    无学生数据    加载失败
          │            │            │
     显示卡片列表  显示空状态    显示重试
          │
    搜索/筛选 → 过滤结果
          │
    ┌─────┼─────┐
    有结果  无结果  清空
    显示    空状态  恢复
```

### 10.2 卡片课时预警状态

```
剩余课时 > 5  →  正常态（主色）
剩余 1-5     →  警告态（琥珀色）
剩余 0       →  危险态（红色）
```

### 10.3 详情页 Tab 切换

```
课时记录 ←→ 课时套餐 ←→ 请假记录 ←→ 家长绑定
  │            │            │            │
  时间轴      进度条        状态标签     邀请码
  卡片列表    卡片列表      卡片列表     + 家长列表
```

### 10.4 详情页操作

```
教师视角：
  [课时充值] → 跳转课时充值页（携带学生ID）
  [编辑]     → 跳转编辑表单页
  [删除]     → 二次确认弹窗 → 删除 → 返回列表

家长视角：
  [家长绑定] → 切换到家长Tab + 滚动到顶部
```
