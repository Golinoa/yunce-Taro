# 课时充值 — UI 设计审查报告

> 审查日期：2026-06-14
> 审查范围：原型文件 + 设计规范 + 迁移方案
> 问题统计：P0: 1 / P1: 3 / P2: 2

---

## 一、业务流程验证

### 核心流程
```
选择学员 → 选择课包(模板/自定义) → 课包信息(仅自定义) → 赠送课时(选填) → 收费信息(选填,含分期) → 确认充值
```

### P0 严重问题

#### P0-1: 充值未实际写入课包数据
**问题**: 点击"确认充值"只显示Toast"充值成功！"，未实际创建课包或更新学员课时余额。`submitBtn` 的 onclick 仅调用 `showToast`。

**影响范围**: 核心功能不可用
**建议**: 确认充值后需：1) 创建新课包记录（关联学员+模板/自定义+课时+有效期）；2) 更新学员剩余课时；3) 如有收费记录，创建收费流水；4) 如有分期，创建分期计划记录。

---

## 二、缺失项识别

### P1 重要问题

#### P1-1: 课包有效期到期提醒缺失
**问题**: 设计中支持设置有效期（N天有效/永久），但充值后无到期提醒机制。学员可能不知道课包即将过期，导致课时浪费。

**建议**: 充值成功后提示"课包将于XXXX年XX月XX日到期"，并在到期前7天/3天/1天推送提醒（与通知设置模块联动）。

#### P1-2: 充值记录入口不明确
**问题**: 导航栏右侧有"记录"按钮，但只显示Toast"查看充值记录"，无实际跳转。充值记录页面的设计缺失。

**建议**: 需设计充值记录列表页：按时间倒序展示充值记录，每项显示学员+课包+课时+金额+时间，支持按学员筛选。

#### P1-3: 自定义课包缺少科目标签
**问题**: 选择模板课包时有科目标签（钢琴/声乐/书法），但自定义课包表单中没有科目选择。自定义课包无法关联科目，影响消课时的课包自动匹配。

**建议**: 自定义课包表单增加"关联科目"选项（从校区设置科目列表中选择，或选择"通用"）。

---

## 三、设计一致性

### P2 一般问题

#### P2-1: 分期金额校验不完整
**问题**: 分期面板中各期金额之和需等于总金额，但当前原型中 `selectPeriod` 只做均分，未处理手动修改某期金额后的重新分配逻辑。

**建议**: 手动修改某期金额后，自动调整剩余期数金额（均分剩余金额），并实时显示剩余金额提示。

#### P2-2: 学员选择弹窗数据硬编码
**问题**: 学员选择弹窗中的学员列表是硬编码的4个学员，与学员管理模块数据不联动。

**建议**: 学员列表应从学员管理模块动态获取，支持搜索和分页。

---

## 四、与其他模块的关联风险

| 关联模块 | 风险 |
|----------|------|
| 学员管理 | 充值后需更新学员剩余课时和课包列表，欠课学员充值后应自动清除欠课状态 |
| 消课流程 | 充值创建的课包是消课时的课包来源，课包科目和有效期需与消课匹配逻辑一致 |
| 校区设置 | 课包模板应从校区设置模块获取，科目列表需与设置一致 |
| 通知设置 | 课包到期提醒需与通知设置模块联动，分期付款提醒也需通知支持 |
