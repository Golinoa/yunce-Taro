### 2.2 卡片设计（方案E 紧凑横条）

**进行中 - 循环上课：**
- 左侧：彩色渐变图标
- 中间：班级名 + 标签行（进行中 + 循环）+ 详情行（人数 + 时间）
- 右侧：∞ 符号 + "循环上课" + 消课箭头按钮

**进行中 - 课时制：**
- 左侧：彩色渐变图标
- 中间：班级名 + 标签行（进行中 + N课时）+ 详情行（人数 + 时间）
- 右侧：进度条（已消/总课时）+ 消课箭头按钮

**已结课：**
- 左侧：紫色渐变图标
- 中间：班级名 + 标签行（已结课 + N课时）+ 详情行（人数 + 时间）
- 右侧：无操作按钮

### 2.3 Tab筛选逻辑

| Tab | 显示内容 | 隐藏内容 |
|-----|---------|---------|
| 全部 | 所有班级 | 无 |
| 进行中 | type=unlimited/limited 的班级 | 已结课分组标题 |
| 已结课 | type=ended 的班级 | 长期班/特训班分组标题 |

筛选无结果时显示空状态提示。

## 三、弹窗设计

### 3.1 创建班级弹窗

底部弹出，包含字段：
1. **班级名称** - 文本输入，必填
2. **上课类型** - 双卡片选择：循环上课(∞) / 课时制(📋)
3. **总课时数** - 数字输入，课时制时显示
4. **上课时间** - 星期多选（7个圆形按钮）+ 时间段（开始-结束）
5. **上课日期范围** - 日期选择器，课时制时显示
6. **授课老师** - 多选胶囊按钮
7. **添加学员** - 点击打开学员选择器

### 3.2 编辑班级弹窗

与创建班级相同，额外：
- 自动回填当前班级数据
- 支持切换上课类型
- 保存后同步更新卡片显示

### 3.3 消课弹窗

底部弹出，包含字段：
1. **上课日期** - 日期选择
2. **消耗课时** - 数字输入
3. **课程内容** - 文本输入，选填
4. **授课老师** - 单选胶囊按钮
5. **签到学员** - 勾选列表，默认全选，支持全选/取消

### 3.4 学员选择器弹窗

底部弹出，包含：
- 搜索框
- 学员列表（头像 + 姓名 + 电话 + 勾选框）
- 已选人数统计
- 确认添加按钮

### 3.5 调班弹窗

底部弹出，包含：
- 标题：将「XXX」调至
- 班级列表（图标 + 名称 + 时间 + 人数 + 类型标签）
- 当前班级置灰标记"当前班级"
- 已结课班级置灰不可选
- 点击目标班级确认调班

```
├─────────────────────────┤
│  上课安排                │
│  每周二、四 14:00-15:30  │
├─────────────────────────┤
│  课时进度                │
│  ████████████████ 循环   │  ← 绿色拉满进度条
├─────────────────────────┤
│  学生列表    ＋添加学员   │
│  ┌───────────────────┐  │
│  │ 张小明  已上8课时 →│  │  ← 可点击进详情
│  └───────────────────┘  │  ← 左滑：调班 | 移除

└─────────────────────────┘
```

### 4.2 已结课班级

- 紫色主题配色
- 课时进度拉满
- 收费与流水（每课时单价、课包价格/人、总流水）
- 上课记录（可展开签到详情）
  - 每条：日期 + 签到人数 + 授课老师
  - 展开后：学生头像 + 姓名列表
  - "+N人"标签点击展开剩余名单
- 底部只有"编辑"按钮，无消课和结课

## 五、学生详情页

从班级详情学生列表点击进入（右滑动画）：

- 头像 + 姓名 + 所属班级
- 统计：已上课时 / 总课时 / 上课次数
- 课时进度条
- 联系方式
- 上课记录列表
- 底部操作：消课 | 调班 | 移除

## 六、交互规范

### 6.1 左滑操作

- 学生条目左滑70px露出"调班"（绿色）
- 继续滑到140px露出"移除"（红色）
- 同时只能滑开一个卡片，滑新卡片自动收回旧卡片
- 点击空白区域收起所有滑动
- 拖拽后不触发点击跳转

### 6.2 卡片左滑

- 班级卡片左滑露出"删除"按钮

### 6.3 长按/右键

- 班级卡片长按弹出上下文菜单

### 6.4 空状态

- 筛选无结果时显示对应空状态提示
- 学生列表为空时显示"暂无学生数据"

### 6.5 加载状态

- 骨架屏样式已定义（CSS类名：skeleton-card）
- 数据加载时显示骨架屏

## 七、数据模型扩展

当前 `Class` 类型缺少以下字段，迁移时需要扩展：

```typescript
interface Class {
  // 现有字段
  id: string;
  name: string;
  teacher_id: string;
  note?: string;
  created_at: string;
  updated_at: string;

  // 新增字段
  type: 'unlimited' | 'limited' | 'ended';  // 班级类型
  status: 'active' | 'ended';                // 班级状态
  schedule: string;                          // 上课时间 "每周二、四 14:00-15:30"
  weekdays: string[];                        // 星期选择 ['二','四']
  start_time: string;                        // 开始时间 "14:00"
  end_time: string;                          // 结束时间 "15:30"
  total_lessons?: number;                    // 总课时（课时制）
  used_lessons: number;                      // 已消课时
  teachers: string[];                        // 授课老师ID列表
  start_date?: string;                       // 开始日期（课时制）
  end_date?: string;                         // 结束日期（课时制）
  color: string;                             // 主题色标识
  student_count: number;                     // 学生数量
}
```
