**校区信息卡片说明**：
- 顶部显示：机构名称（主校区）或校区名称（分校区）+ 类型标签
- 类型标签：主校区/分校区/合作机构，半透明白色背景
- 右侧切换按钮：点击弹出校区选择器
- 下方显示校区地址、电话、统计数据
- 切换校区后，下方所有配置项均对应当前选中校区

**校区选择器弹窗**：
```
┌─────────────────────────┐
│  选择校区            ✕  │
├─────────────────────────┤
│  👑 盛睿艺术    主校区 ✓ │  ← 当前选中项带勾选标识
│  🏢 保利校区    分校区   │
│  🏢 望京校区    分校区   │
│  ✏️ 墨香书法   合作机构  │
└─────────────────────────┘
```

**校区切换逻辑**：
1. 默认选中主校区（不可删除）
2. 点击切换弹出底部选择器
3. 主校区带皇冠图标，选中项显示勾选标识
4. 切换后刷新卡片信息和配置数据
5. 主校区名称自动继承机构名称（单一数据源）

**交互逻辑**：
- 点击卡片进入对应子页面
- 返回按钮返回上级页面
- 校区切换影响所有配置项的生效范围

## 三、弹窗设计

### 3.1 校区编辑弹窗

底部弹出，包含字段：
1. **校区名称** - 文本输入，必填
2. **校区类型** - 自营校区/合作机构（按钮切换）
3. **联系电话** - 手机号输入
4. **校区地址** - 文本输入

### 3.2 科目编辑弹窗

底部弹出，包含字段：
1. **科目名称** - 文本输入，必填
2. **科目图标** - emoji 选择器（30个可选）
3. **科目颜色** - 颜色选择器（6色可选）

### 3.3 节假日编辑弹窗

底部弹出，包含字段：
1. **节假日名称** - 文本输入，必填
2. **开始日期** - 日期选择
3. **结束日期** - 日期选择

## 四、交互规范

### 4.1 导航
- 使用绿色渐变导航栏（与全局一致）
- 返回按钮在左侧（圆形白色半透明背景）
- 添加按钮在右上角（白色半透明背景）

### 4.2 卡片交互
- 点击卡片进入详情页
- 点击编辑按钮打开编辑弹窗
- 点击删除按钮删除（显示Toast提示）
- 按下卡片时缩放 `scale(0.98)`

### 4.3 弹窗交互
- 从底部弹出
- 顶部有拖动把手
- 点击外部或关闭按钮关闭
- 支持表单输入

## 五、数据模型

```typescript
interface Campus {
  id: string;
  name: string;                    // 校区名称
  type: 'self' | 'partner';        // 校区类型：自营/合作
  phone: string;                   // 联系电话
  address: string;                 // 详细地址
  stats: {
    students: number;              // 学生数
    teachers: number;              // 教师数
    revenue: number;               // 本月营收
  };
}

interface Subject {
  id: string;
  name: string;                    // 科目名称
  icon: string;                    // emoji图标
  color: string;                   // 主题色
}

interface SalaryDay {
  dayOfMonth: number;              // 每月第几天发薪（1-31）
}

interface Holiday {
  id: string;
  name: string;                    // 节假日名称
  startDate: string;               // 开始日期
  endDate: string;                 // 结束日期
  type: 'legal' | 'custom';        // 法定/自定义
}

interface NotificationSetting {
  forStudent: {
    classReminderDayBefore: boolean;
    classReminderDayOf: boolean;
    attendanceNotification: boolean;
    classReviewReminder: boolean;
    homeworkReminder: boolean;
    lessonLowReminder: boolean;
    birthdayReminder: boolean;
  };
  forTeacher: {
    classReminderDayBefore: boolean;
    classReminderDayOf: boolean;
  };
}
```
