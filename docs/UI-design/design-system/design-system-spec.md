├─────────────────────────────────────────────────┤
│ L4: 功能入口网格（Feature Grid）                │
│     - 主功能（大图标）、次功能（小图标）          │
├─────────────────────────────────────────────────┤
│ L5: 内容卡片区（Content Cards）                 │

│     - 图标+文字、选中态高亮、安全区域适配        │

## 十、动画规范

### 10.1 基础动画

| 动画类型 | 时长 | 缓动函数 |
|----------|------|---------|
| 进入动画 | 400ms | cubic-bezier(0.16, 1, 0.3, 1) |
| 退出动画 | 300ms | ease-out |
| 状态切换 | 200ms | ease-in-out |

### 10.2 常用动画

#### 10.2.1 脉冲动画（紧急状态）

```css
@keyframes pulse-ring {
0% { box-shadow: 0 0 0 0 rgba(249, 115, 22, 0.35); }
70% { box-shadow: 0 0 0 12rpx rgba(249, 115, 22, 0); }
100% { box-shadow: 0 0 0 0 rgba(249, 115, 22, 0); }
}

.btn-pulse {
animation: pulse-ring 2s infinite;
}
```

#### 10.2.2 滑入动画

```css
@keyframes slideInUp {
from { 
    opacity: 0; 
    transform: translateY(40rpx); 
}
to { 
    opacity: 1; 
    transform: translateY(0); 
}
}

.anim-up {
animation: slideInUp 0.4s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```
