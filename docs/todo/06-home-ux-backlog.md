## 专项：班级消课「补录」联动（lesson-form）

> 用户口径 2026-08-24。页面：`package-course/pages/lesson-form`（班级消课 / 点名页）。  
> 现状：已点名 → `viewMode` 只读 + 底部仅「修改」；另有独立页 `lesson-supplement`（从 lesson-detail 进入）。  
> 目标：**不跳页**，在点名页底部加「补录」，弹窗选人，仅新卡片可编辑，保存只追加记录。

### 页面状态机

```
┌─────────────────────────────────────────────────────────────┐
│  A. 查看态（已点名，默认）                                    │
│  · 全部学员卡片 disabled                                     │
│  · 底部：[全选签到 灰]     [补录] [修改]                      │
└───────────────┬─────────────────────────┬───────────────────┘
                │ 点补录                   │ 点修改
                ▼                         ▼
┌───────────────────────────┐   ┌─────────────────────────────┐
│  B. 补录选人（BottomSheet） │   │  C. 修改态                   │
│  · 学员多选弹窗             │   │  · 全部卡片可点（现有逻辑）    │
│  · 确认添加 → 进入 D        │   │  · 底部：[全选签到] [保存修改] │
└───────────────┬───────────┘   └─────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────────────────┐
│  D. 补录编辑态                                               │
│  · 原学员卡片：disabled（只读，展示已签到/请假/未到）           │
│  · 新增学员卡片：仅此可点，默认 status = 签到                  │
│  · 底部：[全选签到 灰]     [取消] [保存补录]                   │
└─────────────────────────────────────────────────────────────┘
```

### 底部栏规则

| 状态 | 左侧 | 右侧 |
|------|------|------|
| 未点名 | 全选签到 | 提交点名 |
| 已点名 · 查看 | 全选（灰） | **补录** + **修改** |
| 已点名 · 修改 | 全选签到 | **保存修改** |
| 已点名 · 补录编辑 | 全选（灰） | **取消** + **保存补录** |
| 超 24h | 全选（灰） | 已提交（只读） |

按钮顺序：**补录在左，修改在右**（用户明确要求）。

### 补录流程（逐步）

1. 老师进入已点名班级（`scheduleId` + `lessonDate`，`isAlreadyChecked=true`）
2. 默认 **查看态 A**：历史点名结果只读展示
3. 点 **补录** → 打开 **学员选择 BottomSheet**（复用现有 `showAddStudentSheet` 逻辑，数据源 = 非本班学员 / 教师名下学员）
4. 勾选 1~N 人 → **确认添加** → 进入 **补录编辑态 D**
5. 列表顶部/底部插入 **新卡片**（视觉区分：描边 primary / 「补录」角标）
6. **仅新卡片**可切换 签到/请假/未到；默认 **签到**
7. 点 **保存补录** → 二次确认 → **只为新增学员** `lessonRecordService.create`（`status: makeup`），**不删除、不重写**原有记录
8. 成功 → Toast → 刷新列表 → 回到 **查看态 A**

### 修改流程（对齐保存语义）

1. 查看态点 **修改** → **修改态 C**（`viewMode=false`，与现有一致）
2. 全部学员卡片可编辑；底部按钮由「修改」变为 **保存修改**
3. 保存时沿用现有 `handleClassSubmit`：**整节课重算**（先删本班当次占位/签到记录再重建）—— 适合改请假/未到/签到
4. 若用户在修改态又需要加人 → **建议禁用顶部「添加学员」**，统一走 **补录** 入口，避免与整节重算冲突

### 与独立页 `lesson-supplement` 的关系

| 入口 | 行为 |
|------|------|
| lesson-form 底部「补录」 | **本页弹窗 + 仅新卡可编辑**（本次实现） |
| lesson-detail「补录」 | 可保留跳转 `lesson-supplement` 或后续统一为本页 deep link |

推荐：lesson-detail 的补录改为带参跳回 `lesson-form?...&action=supplement`，最终一套交互。
