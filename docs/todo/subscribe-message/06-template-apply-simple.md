# 订阅消息模板 — 去微信申请（对照表）

> 路径：微信公众平台 → 你的小程序 → **功能 → 订阅消息 → 公共模板库**  
> 类型选：**一次性订阅** · 不要长期、不要自己拼自定义  
> 可用类目：**预约/报名 · 办公 · 记账**（哪个搜得到用哪个）

**一共 11 个**（教务 8 + 审批 2 + 机构会员 2）。预约成功 / 自己取消 **不用申请模板**（站内弹框）。课前全部用 ①。

---

## 怎么搜（搜不到就换词）

1. 先按「优先搜」试  
2. 没有就按「备选标题」一个个搜  
3. 标题可以不同，**字段大概对得上**就行（名称 / 时间 / 地点 / 结果类）  
4. 申请完把 **标题 + 模板 ID** 填到文末登记表

## 不要申请这些

| 别搜 / 别加 | 原因 |
|-------------|------|
| 团课/私教/场地预约成功 | 成功只站内弹框 |
| 预约取消（用户自己取消） | 站内提示；机构取消并进 ② |
| 第二个「签到提醒」同标题 | ① 已有；若再申请只作备用，后端用最新一条 |
