## 一、记录原则（用户口径）

1. **只记录重要信息**：涉及**钱 / 课时核销 / 高权限 / 数据变更**的操作才记录；纯查看、登录等无数据变更的行为不记。
2. **点名签到也是重要日志**：批量消课（签到）**记一条汇总日志**（班级/人数/课时）；每个学员的课时消课**明细**由消课记录表（学员详情"课程消耗"）承载，日志与明细可互相印证。
3. **保留策略（2026-08-22 修正）**：日志**后端长期保留（落库不删）**；前端**仅展示最近 90 天**（90 天只是展示上限，不是删除阈值）。
4. **可见范围**：每个人只能看到**自己**的操作日志；**管理者（管理员/校长）可查看下属员工**的全部日志。
5. **不可修改**：日志只追加，无修改/删除接口。
6. 日志信息量：操作人（姓名/角色）、操作对象、详情、时间、结构化上下文（before/after）。

## 九、可见范围矩阵（已实现）

| 角色 | 能看到谁的日志 |
|---|---|
| 管理员（admin） | 全部员工（可切「仅我的」） |
| 校长（principal） | 全部员工（可切「仅我的」） |
| 老师 / 前台 / 自定义角色 | **仅自己**（服务层强制，防越权） |
| 家长 | 无日志入口 |

> 注：当前"管理者看全部"= 机构全量（admin/principal 本就是全量数据）。若后续自定义管理岗（如教学主管）也需要看下属日志，需按**数据范围（campus 校区级）**再细化——本清单暂按"只有 admin/principal 是管理者"处理，**请确认**。
