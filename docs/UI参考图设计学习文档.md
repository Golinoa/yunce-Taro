| Token 名 | CSS 值 | 用途 | 参考图来源 |

**渐变方向规律：**
- 135deg：所有功能图标背景、按钮渐变（参考图统一模式）
- 180deg：页面背景渐变、头部纵向渐变
- 渐变起止色差：HSL 明度差 12%-18%，保持同色系柔和过渡

### 1.6 图标功能色映射

从参考图提取的快捷入口图标配色规范（高频共识模式）：

| 功能 | 图标背景渐变 | 图标前景色 | 参考图来源 |
|------|------------|-----------|-----------|
| 消课/签到 | #5EC8A8 → #7ED8C0 | #FFFFFF | 教培机构_1、教务系统_1 |
| 添加学生 | #9B7ED8 → #B89AE8 | #FFFFFF | 教培机构_2 |
| 课时充值 | #D4A24E → #E0B870 | #FFFFFF | 教培机构_3 |
| 学生管理 | #E88AAA → #F0A8C0 | #FFFFFF | 教培机构_4 |
| 班级管理 | #6BA3D6 → #8DBDE6 | #FFFFFF | 教培机构_5 |
| 课包管理 | #7C6DD8 → #9B8DE8 | #FFFFFF | 教培机构_6 |
| 通知消息 | #F0963C → #F5B06A | #FFFFFF | 教培机构_7 |
| 数据统计 | #5EC8A8 → #4AB090 | #FFFFFF | 教培机构_8 |
| 排课管理 | #6BA3D6 → #93C5E8 | #FFFFFF | 教培机构_9 |

**规律总结：**
- 图标前景统一白色 `#FFFFFF`
- 背景统一 135deg 渐变
- 每个功能对应独立色相，避免混淆
- 同类功能色相相近（如消课/统计同绿色系，班级/排课同蓝色系）

│  └───────────────────────┘   │

### 3.3 圆角使用规律

从参考图总结的圆角设计原则：

1. **层级递增原则**：元素层级越高（越浮起），圆角越大
   - 页面元素 < 卡片 < 弹窗 < 模态框
   - 对应：12px < 16px < 20px < 24px

2. **尺寸递增原则**：元素尺寸越大，圆角越大
   - 标签(4px) < 输入框(12px) < 卡片(16px) < 头部(30px)

3. **功能圆角原则**：
   - 胶囊型（全圆角999）：标签、进度条、手柄 → 表示"流动""连续"
   - 方圆型（固定值）：卡片、按钮、输入框 → 表示"容器""边界"
   - 正圆型（50%）：头像、图标 → 表示"焦点""人物"

4. **参考图圆角统计**：
   - 16px 圆角出现频率最高（约 65% 的卡片使用）
   - 12px 圆角用于输入框和搜索框（约 80%）
   - 20px 圆角用于弹窗顶部（约 90%）
   - 30px+ 圆角仅用于头部过渡（约 70% 的首页类参考图）
