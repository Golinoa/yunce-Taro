## 0. 一句话定位

**泡泡农场** — 云策学员端的积分养宠 + 轻量农场玩法：把「上课、作业、打卡、满勤」等学习行为转化为积分与成长反馈，形成简单闭环，增强续课动力与家校粘性；同学宠物之间可 **PK** 竞技。

---

## 1. 核心玩法循环

```text
        ┌─────────────────────────────────────────┐
        │           学习行为 → 赚积分              │
        │  每节课 · 完成作业 · 积极打卡 · 满勤    │
        └──────────────────┬──────────────────────┘
                           ▼
              ┌────────────────────────┐
              │  积分商城 / 农场商店    │
              └───────────┬────────────┘
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
     购买粮食        购买种子         （预留装饰等）
     喂宠物成长      种庄稼
                          │
                          ▼
                    庄稼成熟 → 出售
                          │
                          ▼
                    获得农场币 / 更多积分
                          │
                          ▼
                    购买高级粮食 → 宠物更快成长
                          │
                          ▼
                    同学宠物 PK（班级/校区榜）
```

**设计原则**：循环要**短、好懂、好反馈**——低龄学员和家长一眼能明白「认真学 → 宠物变强」。

## 2. 积分获取规则（初步）

| 行为 | 触发源（云策现有/规划） | 积分（示例，可配置） | 备注 |
|------|-------------------------|----------------------|------|
| **每节课出勤** | 签到 / 消课成功 | +10 | 每节课结算一次，防重复 |
| **完成作业** | `Homework` 提交且教师确认 | +20 | 可与课后总结、AI 练习联动 |
| **积极打卡** | 课后打卡 / 每日练习打卡 | +5～15 | 连续打卡有加成 |
| **满勤** | 周期内（周/月）出勤率 100% | +50～100 | 周期末一次性发放 |
| **教师奖励** | 教师手动发放（可选） | 自定义 | 表现好额外激励 |

**机构可配置**：各校区 / 机构管理员在后台调整分值、开关某项来源、设置日/周上限（防刷分）。

**与教务真源关系**：积分由**业务事件**驱动（签到、作业状态变更），不由客户端自报。

## 3. 消费与农场经济

### 3.1 双货币（概念）

| 货币 | 获取 | 用途 |
|------|------|------|
| **积分** | 学习行为 | 买基础粮食、买种子、部分装饰 |
| **农场币** | 卖庄稼 | 买高级粮食、稀有种子、PK 道具（可选） |

也可 MVP 阶段**只用积分**一种货币，二期再拆农场币增加层次。

### 3.2 商品类型

| 商品 | 效果 |
|------|------|
| **基础粮食** | 喂宠物 + 经验，便宜、日常消耗 |
| **高级粮食** | 经验加成 / 稀有成长，用农场币或高积分购买 |
| **种子** | 占用农场地块，定时成熟 |
| **庄稼** | 成熟后出售换农场币或积分 |

### 3.3 农场玩法（轻量）

- 每位学员一块**个人农场**（如 3×3 或 4×4 格子）
- 种 seed → 等待 N 小时/天（可离线成熟）→ 收获 → 出售
- **简单循环**：积分买种子 → 种 → 卖 → 换高级粮 → 喂宠

不做重度模拟经营，避免喧宾夺主；核心是**服务学习激励**。

## 4. 宠物系统

### 4.1 领养与成长

- 学员首次进入「泡泡农场」领养一只宠物（名称可自定义，如「泡泡」系列形象）
- 喂食增加经验 → 升级 → 解锁外观 / 动作 / 称号
- 宠物状态：**饱食度、心情、等级**（MVP 可只做等级 + 饱食）

### 4.2 同学宠物 PK

| 维度 | 说明 |
|------|------|
| **范围** | 同班级优先；可选同校区排行榜 |
| **方式** | 轻量对战（比等级、比本周积分贡献、比连续打卡天数等）——**非暴力、偏趣味比拼** |
| **频率** | 每日限次，避免沉迷 |
| **奖励** | 胜方少量积分 / 限定装饰；败方参与奖 |

**原则**：PK 是**社交粘性**，不是 Pay-to-Win；战力主要来自真实学习行为积累的喂养资源。

## 6. 分阶段迭代路径

| 阶段 | 目标 | 交付 |
|------|------|------|
| **F0 · 概念** | 本文档 + 原型图 + 数值表草案 | 无代码 |
| **F1 · 积分骨架** | 事件驱动积分账户 + 明细流水 | 后端 API + 积分账单页 |
| **F2 · 宠物 MVP** | 领养、喂食、升级 | 宠物页 + 基础粮食商店 |
| **F3 · 农场 MVP** | 种 seed、成熟、出售 | 农场格子 UI + 定时成熟 |
| **F4 · 行为挂钩** | 签到/作业/满勤/打卡自动发分 | 对接教务事件 |
| **F5 · PK** | 班级榜 + 轻量对战 | 排行榜 + 每日限次 PK |
| **F6 · 运营配置** | 机构后台调规则、开关 | Admin 配置页 |
| **F7 · 智能体联动** | AI 课后练习完成 → 额外打卡分 | 对接校区智能体 P8 |

> **MVP 建议范围**：F1 + F2 + F4（积分 + 宠物 + 教务挂钩），农场与 PK 可 F3/F5 跟上。

## 7. 数据模型草案（概念）

| 表 / 实体 | 说明 |
|-----------|------|
| `StudentPointAccount` | 学员积分账户（balance、机构隔离） |
| `PointTransaction` | 积分流水（source、amount、refId、幂等键） |
| `FarmCoinAccount` | 农场币账户（可选，F3 起） |
| `Pet` | 宠物实例（studentId、species、level、exp、hunger） |
| `FarmPlot` | 农场地块（studentId、slotIndex、cropId、plantAt、matureAt） |
| `ShopItem` | 商品配置（机构级：粮食/种子/价格） |
| `PetBattleLog` | PK 记录（对手、结果、时间） |
| `GamificationRule` | 机构规则配置（各项分值、上限、开关） |

**幂等**：同一节课签到、同一份作业提交，只发一次分（`refType + refId` 唯一）。

## 9. 开放问题

1. 入口放 Tab 还是学员首页卡片？是否独立分包控制体积？
