# MVP 上线距离评估（对照 `mvp-launch-checklist.html`）

> **日期**：2026-09-01  
> **真源**：`yunce-backend/docs/PM/mvp-launch-checklist.html`  
> **口径**：清单定义「7 步全通 = 可上线」；**不以** NO-GO 全文（会员卡全量 / settings 全写 / 订阅真机）为 MVP 门槛  
> **约束**：1 人 + AI；只评估闭环，不扩家长端/积分商城  

---

## 一句话结论

**按 MVP 清单：约 65–75% 骨架已有，闭环未打穿 → 尚不可上线。**  

在**严格只做清单 P0、不并行 NO-GO 扩张**前提下：

| 情景 | 日历（1 人+AI 满负荷） | 含义 |
|------|------------------------|------|
| **最短可上线** | **5–8 个工作日** | 认证可走 + 机构链路可自洽 + 隔离不串租户 + 一条教务真通 + 真机冒烟 |
| **稳健可上线** | **8–12 个工作日** | 含文案免费版、邀请时长对齐清单、审核策略拍板、首批试用不依赖人工兜底 |
| **若坚持 NO-GO 全清**（会员卡/全 settings/订阅真机） | **+2–4 周** | **超出**本份 MVP 清单范围，会拖死「第一个版本」 |

当前真机待签：**认证 R1**（代码已过）；硬阻塞转 **租户隔离 P0**。闭环未对首批用户开放。

## 清单「7 步闭环」对照代码

| # | MVP 步骤 | 代码现状 | 判 |
|---|----------|----------|-----|
| 1 | 公开注册 + 登录稳定 | 账号密码登录 + 注册落库 + SES 异步；**代码审通过**（Profile.create 无 passwordHash）；真机签收待走查 | ⚠️ 代码过 / 真机待 |
| 2 | 门店入驻（管理员） | 未登录可预览；提交须登录；邮箱软绑；运营审→OWNER+主校区。缺口：pending/JWT org/校区字段/文案「管理员」/B6 预览 | ⚠️ |
| 3 | 创建首个校区 | 审核通过时**自动建默认校区**；校长侧「自建校区」非强依赖 | ⚠️ 部分满足 |
| 4 | 临时邀请码 | `CampusInvite` + staff-invite 有；时长现为 **30m/1h/1d/7d**，清单要 **30m/1h/3h/12h** | ⚠️ 差对齐 |
| 5 | 教师仅邀请加入 | BE 禁教师自助注册；landing+accept 已接；JWT/二次 accept 边角 | ⚠️ 近完成 |
| 6 | 首个教务动作 | 学员/班级/消课主链路多轮 Sprint 已修；依赖有 org 的校长/教师会话 | ⚠️ 依赖前序 |
| 7 | 会员/激活入口预埋 | 会员页 + `redeem-activation-code` 有；FREE 可用；文案「免费版」未必统一 | ✅/⚠️ |

**7 步全绿才算上线 → 第 1 步代码过、真机未签；硬阻塞转隔离与机构开张。**

## 不要算进「第一个 MVP」的（否则永远上不了）

来自 `nogo-elimination-plan` / 历史巡检，**超出**本清单 P0：

- 全部 settings `notWired` 写通  
- 会员卡生产级全链路  
- 订阅消息真机额度页打磨  
- 家长端深化、积分商城、运营任务  
- 课包退款/分期等记账增强  

本版：**预埋入口即可，深做 = 延期。**

## 关键路径缺口优先级（修到能上线）

1. **P0 认证 R1**：SES 异步发码；登录=账号密码；注册=验证码+双密码落库；登录后必达可交互页  
2. **P0 租户隔离**：listTeachers / 校长统计 / 全登录路径带 organizationId  
3. **P0 门店入驻缺口**：pending 状态大小写；批准后 JWT 带 org；校区写入表单字段；文案「机构创建者」（见 store-entry 交接提示词）  
4. **P0 邀请时长对齐** + 教师加入真机签收  
5. **P0 一条教务**真机：有 org 校长 → 学员 → 消课（或建班）  
6. **P1** 免费版文案、会员入口不阻断  
7. **发布**：合法域名、隐私、关 DEV 切换器、`build:weapp:prod`

## 距离感（给决策）

```
[=========>............] ~70% 代码骨架
[===>.................] ~20% 真机闭环签字
[......................] 0%  可对首批陌生用户开放
```

- **不是**「还差三个月从零做」  
- **是**「差一轮聚焦收口：认证 + 机构开张 + 隔离 + 一条教务 + 冒烟」  
- **乐观 1 周、稳健约 2 周**（1 人+AI、不扩 scope）  

若登录 R1 仍拖、或坚持「入驻必须人工审 + NO-GO 全清」并行 → 再 **+1～2 周**。
