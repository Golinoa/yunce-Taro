## 2. 硬约束（下一轮开工前必读）

1. **`border-style` 的 CSS 初始值是 `none`，不是 `solid`**。UnoCSS 的 `border` 工具类**只输出宽度**，
   "实线"由 **preflight** 负责。本项目原先**完全没有 preflight** ⇒ 已用 `preflights` 补上。
2. **现在写边框 = 宽度 + 颜色即可**：`border-[2rpx] border-border` / `border-l-[1rpx] border-destructive`。
   **不再需要**手写 `border-solid`（旧代码保留也无害，重复声明 solid 没有副作用）。
3. 反向陷阱仍在（若 preflight 被移除会复活）：**只写 `border-solid` 不给宽度** →
   未指定的边回退 `medium`(=3px) → 整圈粗框（即 FE-17）。
4. **WXSS 不支持 `*` 通配符选择器** —— 官方支持的选择器只有 `.class` / `#id` / `element` /
   `element, element` / `::after` / `::before`。写 `*` 会让微信开发者工具报
   `./app-origin.wxss(1:…): unexpected token '*'`，**整包编译失败**。
   要在全局重置边框，必须**显式列出组件标签**（元素选择器优先级 (0,0,1) 低于工具类 (0,1,0)，
   所以 `.border{border-width:1px}` 仍能正常覆盖宽度）。
5. 改边框类后**必须核对产物** `dist/app-origin.wxss`（UnoCSS 全局样式只落主包，页面级 wxss 常为空），
   并确认**旧类已从产物 js 中消失**。

## 3. R1（buildId `students-debug-20260923-11`）

**② 现象**（用户 2026-09-23 21:23 原话 + 设计稿/实际两张截图对比）：

> 「你打开的这个是对的 file:…/membership-pricing-v3.html 但是有一个问题 …这是效果图 …这是实际图
> 为什么在实际的代码中 这些边框 颜色都产生了变化呢 卡片的边框什么的都没有了 看起来 是模糊的一片」

对比截图：设计稿 v3 里「选择版本」的四张卡、「开通时长」的卡片、以及卡内嵌的价签卡，
**都有边框与圆角描边**；实际小程序里**所有边框消失**，只剩浅色背景块，块与块之间失去分隔 → "糊成一片"。

**③ 假设**：项目未引入 UnoCSS preflight ⇒ `border-style` 停留在初始值 `none` ⇒
**凡未显式声明 style 的边框一律不渲染**。

**④ 验证方式**（全部是产物/源码事实，不是推理）：

1. 产物 `dist/app-origin.wxss`：`.border{border-width:1px}` —— **只有宽度，没有 style**；
2. 同一文件内通配 `*` 选择器**命中 0 条**（无任何全局兜底）；
3. 全产物 `border-style` 规则只有六条：`.border-2 / .border-dashed / .border-none / .border-solid / .chip / .contact-card`；
4. 全局样式 `src/app.scss`、`src/styles/compat.scss` 中**没有** border reset（只有 box-sizing 与 H5 tabbar 修复）；
5. **反证**：该页唯一正常显示的边框是 `border-dashed`（自带 style）与 `border-t`（项目自定义规则自带 style）
   —— 恰好印证"有 style 就显示、没 style 就不显示"。

**⑤ 结论**：**成立**。5 条证据互相独立且一致。

**⑥ 改动文件**：

- `uno.config.ts`：新增 `preflights`——**只重置 border**，不动 margin / padding / 字体
  （避免引入整份 `@unocss/reset` 造成全站排版漂移）：
  ```ts
  preflights: [{ getCSS: () => `*,::before,::after{border-width:0;border-style:solid;}` }],
  ```
  > ⚠️ **这一版写法是错的**：`*` 会被 WXSS 拒绝（`unexpected token '*'`，整包编译失败）。
  > 正确写法见下方 **R2**。
- `src/package-settings/pages/help/index.tsx:341`：删除 `border-l-[3rpx] border-primary/30`
  —— 用户当天明确表示 FAQ 答案区"**不需要**左侧竖线"；加了 preflight 后它本会**重新显示**，
  故按用户口径一并去掉（保留 `pl-[24rpx]` 缩进）。
- `src/utils/local-debug.ts`：`DEBUG_BUILD_ID` → `students-debug-20260923-11`。

**⑦ 验证结果**：

- 产物 `dist/app-origin.wxss` 出现 `*,::after,::before{border-style:solid;border-width:0}` ✓
  （且全 dist 中只有 `app-origin.wxss` 一处，符合"全局基础样式"定位）。
- 主包 1483.2KB / 1536KB；`verify-pages-complete` 129 页 0 缺失；
  `tsc` 0 错 / `eslint` 0 error / `prettier` 通过 / `vitest` 130 文件 685 用例全绿。

## 4. R2（buildId `students-debug-20260923-12`）—— WXSS 拒绝 `*` 通配符

**② 现象**（用户 2026-09-23 21:51 原话 + 开发者工具报错原文）：

> 「你不用每一次都跑全量测试 UI层面的不影响功能的暂时不需要跑 快速编译即可
> **[ WXSS 文件编译错误] ./app-origin.wxss**
> **`./app-origin.wxss(1:2131): unexpected token `*`**」
>
> 报错行（节选）：`::after,::before,:not(not){…}::backdrop{…}` **`*`** `,::after,::before{border-style:solid;border-width:0}.container{…}`

即 R1 补的 preflight 让**整个小程序包编译失败**（不只是样式不生效）。

**③ 假设**：微信 WXSS 的选择器支持范围比标准 CSS 窄，**不支持 `*` 通配符选择器**。

**④ 验证方式**：
1. 报错位置**正指向 R1 新加的那条** `*,::after,::before{…}`（紧邻的前一条 `::after,::before,:not(not)` 是既有规则，历史上从未报错）；
2. 核对 WXSS 官方支持的选择器清单：`.class` / `#id` / `element` / `element, element` / `::after` / `::before`
   —— **`*` 不在其中**。

**⑤ 结论**：**成立**。根因类的样式判断没错，错的只是"用 `*` 表达全局"这个写法。

**⑥ 改动文件**：
- `uno.config.ts`：preflight 改为**显式元素列表**（WXSS 合法写法）：
  ```ts
  preflights: [
    {
      getCSS: () =>
        'page,view,text,image,scroll-view,swiper,swiper-item,form,label,navigator,' +
        'picker,picker-view,picker-view-column,canvas,video,cover-view,cover-image,' +
        'rich-text,::before,::after{border-width:0;border-style:solid;}',
    },
  ],
  ```
- `src/utils/local-debug.ts`：buildId → `students-debug-20260923-12`。

**⑦ 验证结果**：
- 产物 `dist/app-origin.wxss` 已生成这段规则（注意 **UnoCSS 会把选择器重排**，
  按"我写的顺序"去 grep 会找不到，应按属性反查）：
  ```
  ::after,::before,canvas,cover-image,cover-view,form,image,label,navigator,page,picker,
  picker-view,picker-view-column,rich-text,scroll-view,swiper,swiper-item,text,video,view
  {border-style:solid;border-width:0}
  ```
- 全产物 `[,}]\*[,{]` 模式**命中 0 条** ⇒ 再无通配选择器。
- 主包 1483.3KB / 1536KB；postbuild 正常；`prettier --check` 通过。
- **待用户在开发者工具确认**：WXSS 编译通过 + 会员页边框恢复。

## 5. 影响面与回归说明

- **改动性质**：从「不显示」变为「按代码原意显示」，**不改变任何原本已正常显示的元素**。
- 已核实的正常显示项**不受影响**：`.border-2`、`.border-t`、`.border-dashed`、`.chip`、`.contact-card`
  （它们都自带 `border-style`，preflight 只是补充而非覆盖）。
- 回归重点页面：**订阅会员页**、首页、课表、学员管理、设置 / 使用帮助。
- 若某处出现**不该有**的边框：处理方式是**就地删掉那个 class**，
  **不要**回退 preflight（回退会让 164 处重新集体消失）。
