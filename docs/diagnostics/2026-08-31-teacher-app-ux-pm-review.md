# 教师端用户路径体验走查（产品视角）

> **视角**：产品经理 · 用户体验与流程合理性  
> **对象**：教师角色（`teacher` / `assistant`）主路径  
> **依据**：前后端联合走查报告 + 全量路径附录（2026-08-31）  
> **原则**：按用户任务流审视「预期 vs 实际」，问题按对业务/体验的伤害从高到低排列

---

## 一、教师核心任务流（先建立心智模型）

教师日常高频任务可归纳为：

```
到校开课 → 看今日课/待办 → 点名消课 → 处理请假/试听/补课
         → 跟进学员与续费 → 查看本人课时/工资 → 收尾设置
```

主入口分布：

| 任务 | 用户自然入口 | 当前落点 |
|------|--------------|----------|
| 今日上课 | 首页今日课 / 课表 | ✓ 较顺 |
| 点名消课 | 课表卡片 /「快速消课」 | ✓ 主链路通，支线有坑 |
| 处理待办 | 首页待办卡片 | ✗ 部分跳到无权限页 |
| 建档/充值 | 金刚区 | ✓ 能进，完成后易断 |
| 看自己的课消/工资 | 「我的」教学台账 | ✗ 数据可信度低 |
| 审批请假 | 课表/详情/待办 | △ 教师可走，校长断 |

下文问题均挂在上述任务流上。

---

## 二、问题清单（按严重程度排序）

### P0 · 致命：任务做到一半被系统「踢回」或数据不可信

---

#### 1. 待办点击后提示「无权限」并回首页

| 项 | 说明 |
|----|------|
| **所在环节** | 首页 → 待办卡片（薪资提醒 / 经营预警 / 部分补点名） |
| **用户预期** | 点待办应直接处理该事项 |
| **实际结果** | 薪资待办进发薪页、预警进经营看板、部分点名进「课程管理」——均为校长/管理员页；教师被 Toast「无权限」并打回首页 |
| **体验影响** | **信任崩塌**：系统主动催办，却不让处理；高频入口变成死胡同，待办形同虚设 |
| **优化建议** | ① 待办跳转按角色分流：教师薪资→「教学台账·工资」；预警→学员详情/续费提醒；点名必须带课次参数，缺参则进课表今日视图。② 生成待办时写入可达 URL，禁止指向管理端页。③ 若确需校长处理，文案改为「请联系校长」且不可点进无权限页 |

---

#### 2. 「我的」核心数据始终为 0；教学台账/工资明细像「演示数据」

| 项 | 说明 |
|----|------|
| **所在环节** | 我的 → 顶部四格统计；教学台账 → 课时/工资；工资单明细 |
| **用户预期** | 看到真实出勤、课时、应发/实发 |
| **实际结果** | 统计恒为 0；台账生产仍走 Mock；工资明细页用本地假流水 |
| **体验影响** | **核心价值页失信**：教师无法核对本月课消与工资，产生「系统不准/白干」的焦虑，客服与校长对账成本上升 |
| **优化建议** | ① 无真数据时：隐藏四格或展示「数据开通中」，禁止显示假 0/假流水。② 台账接真实课消与薪资接口；工资单仅展示后端明细。③ 上线前用「空态设计」替代 Mock 冒充 |

---

#### 3. 添加学员成功后，引导去「班级管理」却被拦截

| 项 | 说明 |
|----|------|
| **所在环节** | 首页「添加学员」→ 保存成功 → 后续引导 |
| **用户预期** | 保存成功后回到学员列表，或继续给该学员分班/充值 |
| **实际结果** | 可跳转「课程管理（班课）」——教师无权限 → 回首页 |
| **体验影响** | **闭环断裂**：刚完成建档的高意图时刻被打断，下一步动作丢失，易重复建档或放弃分班 |
| **优化建议** | 教师保存后：`navigateBack` 学员列表并高亮新学员，或直达「学员详情 / 课时充值」；「去班级」仅对校长展示 |

---

#### 4. 点名页提供「编辑班级」，教师一点即无权限

| 项 | 说明 |
|----|------|
| **所在环节** | 课表 → 点名/消课页 → 编辑班级 |
| **用户预期** | 能改本班备注/名单，或根本看不到不可用入口 |
| **实际结果** | 入口可见，跳转管理端班级编辑页后被拦 |
| **体验影响** | 课中高频场景出现「诱饵按钮」，干扰点名节奏 |
| **优化建议** | 教师角色隐藏该入口；若仅需改助教/教室，提供教师可用的轻量编辑，而非整页课程管理 |

---

### P1 · 严重：流程不顺、预期错位、关键反馈缺失

---

#### 5. 「教学台账」内「我的预约」Tab 无法停留，强制跳走

| 项 | 说明 |
|----|------|
| **所在环节** | 我的 → 教学台账 → 切换「我的预约」 |
| **用户预期** | 同页三个 Tab 切换查看流水 |
| **实际结果** | 选中即 `redirect` 到独立预约页，台账上下文（月份摘要）丢失 |
| **体验影响** | 信息架构自相矛盾；同入口「我的预约」在外层直达、内层又跳转，步骤冗余且迷路 |
| **优化建议** | 二选一：台账内嵌预约列表；或去掉该 Tab，只保留外层入口。禁止「Tab 伪装成导航」 |

---

#### 6. 营销活动四个入口全部「开发中」

| 项 | 说明 |
|----|------|
| **所在环节** | 我的 → 营销活动（秒杀/拼团/优惠券/邀请有礼） |
| **用户预期** | 可配置或至少查看活动 |
| **实际结果** | Toast「努力开发中」 |
| **体验影响** | 占屏幕、占心智，强化「半成品」印象；与教学主任务无关却前置展示 |
| **优化建议** | 未上线模块对教师整区隐藏；或收敛为一个「活动中心·即将上线」说明页，避免四个假入口 |

---

#### 7. 考勤相关命名与真实能力错位

| 项 | 说明 |
|----|------|
| **所在环节** | 深链/旧入口「考勤」→ 瞬间跳到「上课记录」；金刚区历史文案残留「考勤」语义 |
| **用户预期** | 上下班签到，或班级考勤看板 |
| **实际结果** | 无签到能力，直接变成课消列表 |
| **体验影响** | 词汇与能力不符，教师找「打卡」无门；与「上课记录」入口重复 |
| **优化建议** | 统一对外文案为「上课记录/课消」；签到未上线前删除考勤入口与深链，或落地页明确「员工签到下版开放」并给替代入口 |

---

#### 8. 校长走「请假审批」时流程在权限上断裂（跨角色但同 Staff 产品）

| 项 | 说明 |
|----|------|
| **所在环节** | 课表/学员详情 → 请假审批（Staff 共用 UI） |
| **用户预期** | 校长作为管理者应能批假 |
| **实际结果** | 前端按机构端开放，后端接口仅教师/家长 → 校长 403 |
| **体验影响** | 机构里最终决策人无法闭环，家长催审批时校长「看得见点不了」 |
| **优化建议** | 后端放行校长并限定校区范围；前端失败时明确「审批失败，请重试/联系技术」，禁止静默空列表 |

---

#### 9. 工资/课时「看得见入口、看不清结果」

| 项 | 说明 |
|----|------|
| **所在环节** | 我的 → 工资记录；深链工资单 |
| **用户预期** | 从台账能钻到正式工资单，核对明细 |
| **实际结果** | 台账有工资 Tab，但无清晰「工资单」入口；工资单页又可能是 Mock |
| **体验影响** | 发现性差 + 可信度低，教师仍找校长口头对账 |
| **优化建议** | 「工资记录」列表项可点进本人工资单；仅展示已发放/已确认数据；未出账显示空态「本月尚未核算」 |

### P2 · 一般：冗余、边界弱、反馈不够清晰

---

#### 10. 入口过多、语义重叠（金刚 8 + 三卡片 3 + 台账 4）

| 项 | 说明 |
|----|------|
| **所在环节** | 首页首屏、我的台账 |
| **问题** | 「上课记录」「我的预约」「快速消课」多处可达；充值/添加学员对一线教师是否刚需因校而异，却与教学入口平权 |
| **影响** | 首屏噪音大，新教师学习成本高 |
| **建议** | 教师首屏收敛为：今日课、待办、消课、学员、线索；充值/续费等降为二级「教务工具」 |

---

#### 11. 充值记录等列表「到站即止」，缺少下钻

| 项 | 说明 |
|----|------|
| **所在环节** | 金刚 → 充值记录 |
| **问题** | 多为列表展示，缺少进学员/课包的明确下一步 |
| **影响** | 发现问题后还要搜学员，步骤冗余 |
| **建议** | 行点击进学员详情对应课包；异常金额高亮并给「去处理」 |

---

#### 12. 异常与边界：空态、失败、无权限文案单一

| 项 | 说明 |
|----|------|
| **所在环节** | 全局守卫拦截、列表加载失败、无学员时点名 |
| **问题** | 无权限统一「无权限访问该页面」；用户不知道下一步找谁；部分空列表缺少行动按钮 |
| **影响** | 受挫后只能退出乱点 |
| **建议** | 无权限文案区分「需校长处理 / 功能未对教师开放」；空态带主按钮（去排课/去添加学员） |

---

#### 13. 教师可误入家长向页面（深链/分享）

| 项 | 说明 |
|----|------|
| **所在环节** | 我的课包、孩子列表、课后作业等家长页 |
| **问题** | 无角色互斥时教师深链可进，数据为空或错乱 |
| **影响** | 困惑「是不是登错身份」 |
| **建议** | 家长页强制 `parent` 守卫；误入时引导切回教师身份 |

---

#### 14. 功能已注册但产品无入口（转校、约课规则等）

| 项 | 说明 |
|----|------|
| **所在环节** | 学员转校、约课规则、教师约课配置等 |
| **问题** | 能力存在或占位，教师路径上找不到 |
| **影响** | 需求来了只能口头/表格处理，系统价值下降 |
| **建议** | 排期补入口，或从产品范围明确下线，避免半隐藏能力 |

---

### P3 · 建议：体验打磨

| # | 环节 | 问题 | 建议 |
|---|------|------|------|
| 15 | 课表操作密度 | 点名/试听/请假/左滑编辑密集，误触风险（已有锁但心智负担高） | 主按钮只保留「点名」；次要收入「更多」 |
| 16 | 关于页/门店入驻 | 教师点关于可能摸到入驻入口再被拦 | 按角色隐藏 |
| 17 | 主题色等设置 | 文档与实际可见性不一致，培训口径混乱 | 统一产品说明：个人主题教师可用 |
| 18 | 成功反馈 | 部分写操作仅 Toast，缺少结果页摘要（如消课成功人数） | 关键写操作后给一屏结果+「回到课表」 |

## 三、流程顺畅度总评（产品结论）

| 任务流 | 顺畅度 | 一句话 |
|--------|--------|--------|
| 课表点名/补录主路径 | ★★★★☆ | 主干可用，支线按钮越权 |
| 首页待办驱动处理 | ★☆☆☆☆ | 催办与可达性严重不一致 |
| 建档→分班/充值 | ★★☆☆☆ | 建档后引导断裂 |
| 本人课消/工资核验 | ★☆☆☆☆ | 数据与入口双重问题 |
| 线索/试听/代约 | ★★★☆☆ | 路径较全，信息架构略深 |
| 我的页信息架构 | ★★☆☆☆ | 假数据 + 占位营销拖累信任 |

**优先改什么（产品排序）**：  
1）待办可达性与角色一致（立刻止血信任）  
2）禁止假 0 / 假工资，空态诚实  
3）建档与点名页去掉「诱饵式」管理端跳转  
4）台账 IA 收敛（预约 Tab）  
5）隐藏未上线营销与错误考勤语义

## 四、验收标准（改完怎么算过）

1. 教师账号点击首页每条系统待办：**不会**出现「无权限回首页」；要么能办结，要么文案说明转交校长且不可误点。  
2. 「我的」四格与台账：要么真数，要么明确空态，**禁止恒 0 / Mock 冒充已发工资**。  
3. 教师从「添加学员」保存后：**留在学员相关闭环**，不进课程管理。  
4. 点名页教师视角：**不可见**无权限的「编辑班级」。  
5. 教学台账三个 Tab：**同页可切换**或去掉会跳走的 Tab。
