## 如何判断成功

| 判定        | 含义                                                               |
| ----------- | ------------------------------------------------------------------ |
| ✅ 通过     | 页面打开、数据来自服务端、关键操作成功且刷新后仍在、无假成功 Toast |
| ⚠️ 已知占位 | 明确「功能开发中 / 即将上线 / 接口未开通」且**无假成功**           |
| ❌ 失败     | 白屏、403/500、无限加载、假成功、数据与身份不符、越权能进管理页    |

网络面板：请求应打到 `dev.chancore.cn`，不要出现本地 mock 假数据特征。
