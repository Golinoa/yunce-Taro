🔒 走查冻结规则（持久化）

  1. 已通过项 = 冻结链路：标记为「通过」的走查项，其关联代码路径视为已验收冻结，后续优化不得静默改动。
  2. 每次优化必须评估影响范围：改动前对照下方「冻结链路注册表」；若 diff 触及冻结路径上的文件/接口，须先完成影响评估。
  3. 受限即询问：评估结论为「可能影响已验收链路」时，必须先与用户确认，不得直接改代码。
  4. 记录反馈：走查完成后点击「导出 JSON」，将文件发给 Agent 或提交到 device-walkthrough-record.json。
  5. 失败项：标记「失败」并填写备注，修复后重新走查该项，通过后再冻结。
