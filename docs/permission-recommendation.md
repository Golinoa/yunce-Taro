## 一、教培机构常见岗位清单（含职责与权限建议）

| 岗位 | 对应系统角色 | 职责 | 默认数据范围 | 默认可见模块 | 备注 |
|---|---|---|---|---|---|
| 机构负责人（创始人） | **admin** | 建机构、付房租/运营、财务决策 | all | 全部 | 唯一可分配权限的角色 |
| 校长/校区负责人 | **principal** | 校区日常运营、排课审批、业绩 | all | 除 settings 外全部 | 由 admin 任命与授权 |
| 教学主管 | 自定义角色（基准 teacher） | 管老师排课、教学质量、试听转化 | campus | salary/students/classes/leads | 常见自定义岗位 |
| 财务/教务专员 | 自定义角色（基准 assistant） | 收银、消课对账、会员卡 | campus | students/finance | 常见自定义岗位 |
| 全职老师 | **teacher** | 上课、点名、看自己学生 | own | students/classes/leads/salary(本人) | 可被授权扩大 |
| 兼职/实习老师 | 自定义角色（基准 teacher） | 代课 | own（缩小：仅本人班级） | classes | 建议关闭 leads/salary 查看 |
| 前台/教务助理 | **assistant** | 接待、约试听、办卡 | own | students/classes/leads | 无薪资权限 |
| 市场/地推 | 自定义角色（基准 assistant） | 拉新线索 | own | leads | 只给线索模块 |
| 家长 | **parent** | 看绑定孩子 | own（绑定孩子） | students（仅绑定孩子） | 未绑定则无数据 |

## 三、管理员可动态开关的数据项（授权粒度）

按「**数据模块 × 数据范围**」两维授权：

- **模块粒度（7 项）**：薪资 / 学员 / 班级·课程 / 线索·试听 / 经营数据 / 员工管理 / 系统设置
- **范围粒度（3 档）**：仅本人数据（own）/ 本校区数据（campus）/ 机构全部数据（all）
- **组合示例**：
  - 给教学主管：「学员·本校区」+「班级·本校区」+「薪资·本校区」→ 可管理校区教学，不可看财务
  - 给财务：「学员·本校区」+「经营数据·本校区」→ 可对账，不可看薪资明细
  - 兼职老师：「班级·仅本人」→ 只能看自己带的班

## 四、常见场景深度推理

### 场景 1：多校区机构
- 校长按校区任命，`campus` 范围区分校区；跨校区校长给 `all`
- 建议：授权 UI 后续支持按校区分别配置（P2），当前 scope 粒度先覆盖单校区/全机构

### 场景 2：老师离职/停课
- 立即回收：把该老师的 `teacher` 授权降为「仅本人-无模块」或删除其身份
- 历史数据不删（学员转给其他老师），离职走 `resignTeacher`

### 场景 3：家长多孩 / 换机构
- 家长身份绑定多个孩子（同一机构内）；换机构需重新绑定
- 未绑定孩子 → 所有数据为空（`hasBoundChild` 判定），前端给出"去绑定"引导

### 场景 4：前台约试听但不看经营
- assistant 默认无 `finance`，无法看到收入/成本，防止前台误触或泄密

### 场景 5：教学主管看薪资
- 教学主管常需核对老师课时费 → 给 `salary`（校区范围）；若机构不希望主管看薪资，关闭即可

### 场景 6：自定义角色应用于具体员工
- 当前 mock 阶段：自定义角色作为模板保存（P1 在员工管理分配角色给员工）
- 联调后：后端「用户-机构-角色」表落地，员工身份上挂自定义角色

## 五、自定义角色设计建议

1. **命名**：岗位名（教学主管/财务/市场/兼职老师），而非权限描述
2. **基准**：从最接近的系统角色继承（teacher/assistant），减少配置成本
3. **模板化**：沉淀「教学主管模板」「财务模板」，新机构一键套用（P2）
4. **分配**：员工管理页「分配角色」下拉（系统角色 + 自定义角色）（P1）

## 六、默认权限配置模板（给机构快速上手）

```
机构刚开业（<10 员工）：
  admin  → 全量
  principal → 全部（除系统设置）
  teacher → 本人数据 + 学员/班级/线索/本人薪资
  assistant → 本人数据 + 学员/班级/线索
  自定义「财务」 → 学员·本校区 + 经营数据·本校区

机构成熟（多校区/多部门）：
  教学主管 → 学员·本校区 + 班级·本校区 + 薪资·本校区
  市场    → 线索·本校区
  兼职老师 → 班级·仅本人
```

## 七、安全边界（重要）

- **前端拦截只是体验层**：URL 直跳、接口越权必须由**后端强校验**（403/空数据）兜底
- 权限变更即时生效：保存后重新进入页面即按新配置校验
- 敏感操作（发薪/删除/大额充值）建议保留二次确认 + 审计日志（P3）
