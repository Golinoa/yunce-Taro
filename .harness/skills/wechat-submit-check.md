# Skill: 微信提审自检

> 配套规则：`.harness/rules/80-compliance.md`。任一项不通过，结论就是「不能提审」，并列出缺什么配置。

## 协议与隐私

- [ ] 登录 / 注册页有协议勾选或弹窗，可打开完整协议页
- [ ] 《个人信息保护指引》已在公众平台发布，且与代码实际收集项一致
- [ ] 协议页 + 后台指引 + `requiredPrivateInfos` 三者一致
- [ ] `__usePrivacyCheck__` 为合规开启状态（临时 `false` 只是过渡）

## 接口与授权

- [ ] 所有调用的隐私接口都在 `requiredPrivateInfos` 中声明
- [ ] 无未声明隐私接口、无强制索权
- [ ] 拒绝授权时有降级路径，不崩溃、不白屏
- [ ] 真机验证过选图 / 定位等授权弹窗链路

## 内容与业务

- [ ] 主包 / 分包体积与「服务类目」页面路径匹配，无空洞页
- [ ] 正式包中无测试页、无 Mock 开关、无调试后门
- [ ] 无诱导分享 / 诱导关注 / 虚假功能 / 死链
- [ ] 对外名称「松果排课」与类目、简介、截图一致
- [ ] 涉及资金的页面未伪造支付成功态，金额与后端一致

## 权限与数据隔离

- [ ] 家长只能看到自己的孩子
- [ ] 教师按 scope 过滤
- [ ] 校长 / 管理员按校区过滤
- [ ] 权限不足时有空态提示，而非白屏
- [ ] 前端隐藏入口之外，接口失败也有无权限态

## 安全

- [ ] 控制台无敏感信息输出
- [ ] 日志 / Toast 未泄露身份证、卡号、验证码、Token
- [ ] 正式环境域名已备案且配置为合法域名

## 运营侧

- [ ] 用户可在「我的 / 设置」再次查看协议与说明
- [ ] UGC / 反馈具备治理路径（举报 / 屏蔽）

## 提交

提审走 `v*` 标签触发 `release.yml`（prod 构建 + `upload:weapp`），**必须经用户明确确认**。
